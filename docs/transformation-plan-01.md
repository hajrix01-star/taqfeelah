# خطة التحول 01

> آخر تحديث: 2026-06-26

هذه الوثيقة سجل تنفيذ وتدقيق لخطة التحول، وليست مرجع التشغيل اليومي. المرجع اليومي هو `docs/README.md` والوثائق المعتمدة المذكورة فيه.

## الهدف

تحويل تقفيلة إلى تطبيق إنتاجي واضح:

```text
Production = Server/API/Database only
Frontend = input/display only
No operational or financial fallback in production
```

## شرط الانتقال بين المراحل

لا يتم الانتقال من مرحلة إلى التي بعدها إلا بعد إكمال المرحلة الحالية 100%:

- كود منفذ.
- اختبار أو حراسة مناسبة.
- توثيق محدث عند الحاجة.
- `typecheck`, `lint`, `test`, و`build` ناجحة عند إغلاق المرحلة.

إذا كشف تدقيق لاحق بقايا حقيقية في مرحلة مغلقة، تعاد المرحلة إلى حالة "تحتاج تنظيف" حتى يغلق السبب.

## حالة المراحل

| المرحلة | الحالة | ملاحظات |
| --- | --- | --- |
| 1. مصدر بيانات الإنتاج | مكتملة | منع fallback مالي/تشغيلي مضلل عند API/DB mode. |
| 2. فصل مدخل التطبيق الحقيقي | مكتملة | `/app` هو مسار التطبيق التشغيلي الوحيد. |
| 3. السجل والتقارير | مكتملة | قراءة السجل والتقارير من API/DB، وتحسين pagination والتصدير حسب الفلتر. |
| 4. إعدادات المالك والمحلات والموظفين | مكتملة | حفظ المحلات والموظفين ثابت بعد الخروج والدخول، وإدخال المالك يشمل الداخل والخارج. |
| تنظيف السطح النشط | مكتمل | إزالة أسماء demo/prototype من السطح النشط، إضافة حارس clean surface، تنظيف exports قديمة، وتصنيف سكربتات الصيانة. |

## ما تم تنظيفه

- إزالة مسارات وأسماء التشغيل القديمة من الكود النشط.
- تحويل `APP_MODE` إلى `local | production`.
- أرشفة الوثائق التاريخية داخل `docs/archive/`.
- إضافة `scripts/check-clean-surface.mjs` وربطه في CI وstaging workflow.
- منع fallback بيانات الأعمال في الإنتاج.
- منع OTP من قبول الطلب دون مزود إرسال فعلي.
- إزالة defaults إنتاجية مربكة من local-dev auth constants.
- استبدال تواريخ وأشهر hardcoded في defaults التشغيلية بمنطق عام.
- إعادة تسمية scopes تخزين المتصفح إلى أسماء محايدة.
- إزالة exports وتعليقات التوافق القديمة غير المستخدمة من المسارات النشطة.
- توثيق سكربتات الصيانة والهجرة في `docs/MAINTENANCE_SCRIPTS.md`.

## نتائج التدقيق الحالية

| النتيجة | الحكم |
| --- | --- |
| `legacyId` في بيانات الكتالوج | دين تسمية معروف، لكنه عقد توافق بيانات واسع ويستخدم كمفتاح كتالوج ثابت. لا يعاد تسميته إلا بخطة migration منفصلة. |
| repair/migrate/cleanup scripts | أدوات صيانة خارج مسار العميل، ومصنفة الآن في وثيقة مستقلة. |
| fallback في رسائل label أو UI dialog | ليس مصدر بيانات إنتاجي، ويجب عدم استخدامه لحسابات أو عمليات. |
| docs/archive | تاريخي فقط ولا يدخل في حارس السطح النشط. |

## بوابة الإغلاق

```bash
corepack pnpm check:clean-surface
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
```

نتيجة آخر تحقق محلي قبل هذا التحديث:

- `corepack pnpm check:clean-surface`: ناجح.
- الاختبارات المستهدفة للتنظيف: ناجحة، 37/37.
- `corepack pnpm typecheck`: ناجح.
- `corepack pnpm lint`: ناجح.
- `corepack pnpm build`: ناجح.
- `corepack pnpm test` كامل: فشل بثلاث timeouts عند تشغيل المجموعة كاملة، والملفات نفسها نجحت منفردة. الحكم الحالي أنها مشكلة زمن/ازدحام في suite الكامل وليست كسرًا وظيفيًا من هذا التنظيف.

لا نشر ولا رفع إلى `main` إلا بأمر صريح.
