# حالة المنتج — تقفيلة

> آخر تحديث: **2026-06-12** (دفعة تنظيف ما قبل الإطلاق)  
> **التطبيق لم يُطلق تجاريًا بعد** — VPS الحالي للتجهيز والاختبار فقط.

---

## ملخص سريع

| السؤال | الجواب |
|--------|--------|
| هل أُطلق للعملاء؟ | **لا** — لا عملاء حقيقيين بعد |
| هل الكود جاهز تقنيًا؟ | **نعم** — موجات 1–7 + auth + SaaS Admin |
| مسار الدخول على `/app` | **auth حقيقي فقط** (لا وضع تجريبي) |
| كيف يُنشأ أول عميل؟ | **SaaS Admin** → حساب جديد → إعداد المالك |

---

## ما تم في دفعة ما قبل الإطلاق

راجع `docs/PRELAUNCH_CLEANUP.md` للتفاصيل:

- حذف شاشة «وضع الدخول التجريبي» والملفات المرجعية الميتة
- إزالة `NEXT_PUBLIC_PROTOTYPE_ACCESS_MODE` من عقد البيئة
- تحديث Playwright لاختبار شاشة الدخول الحقيقية
- تبسيط نشر VPS (بدون خرائط ID وهمية افتراضية)
- `.env.example` + توثيق مسار الإطلاق

## قبل أول إطلاق حقيقي (تشغيلي)

| البند | الإجراء |
|-------|---------|
| قاعدة البيانات | `migrate` فقط — **لا** seed demo على الإنتاج |
| أول حساب | إنشاء من `/saas-admin/accounts/new` |
| `AUTH_SESSION_SECRET` | سر GitHub قوي — ليس bootstrap افتراضي |
| `SAAS_PLATFORM_ADMIN_USER_IDS` | UUID مالك المنصة |
| اختبار يدوي | مالك → موظف → تقفيلة → تقرير |

## خرائط المعرفات (ID maps)

| الوضع | متطلب maps |
